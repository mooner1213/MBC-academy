# 게임 시스템 디자인

### 스프레드시트 기초
> 데이터를 수집하고 보관하는 '소통 가능한 그릇'

**스프레드시트란?**

* 데이터를 수집, 보관, 조작하여 의미있는 정보를 찾아내는 강력한 도구
* 사용자 간 소통이 가능한 구조로 설계되어 있다.

### 셀(Cell)구조의 이해

**데이터 저장 구조**
1. 셀 & 열/행 : 데이터의 가장 작은 단위인 셀이 모여 열과 행의 체계를 이룬다.
2. 시트 : 관련된 데이터들을 한 화면에 모아놓은 작업 공간
3. 통합문서 : 여러 시트를 포함하는 하나의 파일 단위

**셀의 3대 요소**
1. 셀 주소 : 열과 행의 교차점
2. 셀 값 : 텍스트, 숫자 등 저장되는 원본 데이터
3. 셀 수식 : 결과값을 자동으로 계산하는 입력식

**수식 입력 줄, 주요기호**

* 수식 입력 줄 : 셀의 겉모습과 상관없이 내부에서 일어나는 실제 데이터나 수식을 확인하고 수정할 수 있다.
* 필수 기호 : 수식의 시작인 =, 그룹화를 위한 (), 문자열을 위한 "" 등을 자주 사용한다.
* 연산자 : 기본 사칙연산(+,-,*,/)부터 거듭제곱(^), 텍스트 결합(&) 까지 다양한 계산이 가능하다.

**시트를 깔끔하게 유지하는 팁**

* 별도 시트 참조 : 시트별로 데이터를 정리하고 수식으로 연결하여 관리 효율을 높인다.
* 데이터 숨기기 : 불필요한 행/열을 숨겨 가독성을 높여도 수식은 여전히 작동한다.
  * (원하는 행/열을 **우클릭 + H** / 취소하는 법은 **숨긴열 양쪽 행/열 드래그 후 우클릭 + U**)
* 틀 고정 : 데이터가 많을 때 레이블(제목)을 상단에 고정하여 정보를 쉽게 확인한다.
    * (**보기 탭**의 틀 고정을 사용하자.)

**소통을 위한 댓글, 메모**

**업무 효율 3가지 기능**

* 자동 채우기 : 수식이나 데이터를 여러 셀에 걸쳐 빠르게 복제하여 단순 반복 작업을 제거한다.
* 필터 : 유저가 정의한 조건에 맞는 데이터만 선별하여 보여줌으로써 분석에 집중하게 한다.
* 데이터 확인 : 유효성 검사를 통해 입력 가능한 형식을 제한, 드롭다운 목록으로 오입력을 방지한다.
