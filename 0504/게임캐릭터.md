# 게임 캐릭터

### 캐릭터를 구성하는 3가지 노드
> 휼륭한 게임 캐릭터는 이 세가지 요소가 완벽하게 계산된 시스템으로 설계된다.

* **외면적 요소** : 캐릭터의 시각적 외형과 인상
* **내면적 요소** : 캐릭터의 가치관과 성격
* **기능적 요소** : 게임 시스템과 결합된 플레이 매커니즘

**유기적 연결망**

* **대사** : 내면과 외면이 만나 발화됨.
  * 대사의 해부학 : 내면적 요소 + 외면적 요소

* **게임시스템** : 외형이 게임의 규칙/기능을 시각적으로 반영함.
  * 매커니즘 방정식 : 외형과 시스템의 융합

* **행동 & 스토리 역할** : 성격과 가치관이 기능적 행동으로 발현됨.

### 직업 : 서사적 설득력의 핵심

* 게임에서 서사적인 측명을 고려할 때, 직업은 그 자체로 가장 강력한 설득력을 지닌다.
* 직업을 보는순간 캐릭터의 과거, 현재, 그리고 행동방식을 즉각적으로 납득한다.

### 전투 매커니즘 : 정체성의 최종 완성
> 무기를 휘두르는 궤적, 스킬의 쿨타임, 타격의 피드백 등 전투 매커니즘은 간순한 숫자가 아니라

> 캐릭터의 영혼(정체성)을 증명하는 시스템적 언어이다.

### 캐릭터 체크리스트

1. 외면적 키워드가 시각적으로 명확한가?
2. 내면의 가치관이 대사로 일관되게 발화 되는가?
3. 기능적 매커니즘이 캐릭터의 직업/정체성을 완벽히 대변하는가?

# 스토리 모델
> 내적 갈등, 외적 갈등과 같은 장애물을 극복하는 과정이 어려워야 한다.

| | |
|--- | ---|
|주인공 | 스토리의 중심이 되는 인물 |
| 목표 | 주인공이 스토리상에서 이루고자 하는 것 |
| 적대자 | 주인공이 하는일을 방해하는 존재 |
| 조력자 | 주인공이 하는 일을 돕는 존재 |

### 스토리 아키텍트 진단 체크 리스트

1. 기반설계 : 트라우마와 내적갈등이 명확한가?
2. 갈등의 역학 : 내적갈등과 외적갈등이 맞물리는가?
3. 변화와 주제 : 목표달성 후 어떻게 달라졌는가?

### 캐릭터 제작 프로세스

1. 설정
2. 원화
3. 모델링
4. 리깅
5. 애니메이션
6. 이펙트
7. 캐릭터 데이터

### 성격의 양면성

* 긍정적 성격 : 캐릭터의 장점. 플레이어가 응원하게 만들며, 목표를 이루는 데 직접적인 도움을 준다.
* 부정적 성격 : 캐릭터의 결핍. 약점이 되기에 오히려 매력적일 수 있으며, 목표를 이루는 데 방해요소로 작용.

### 파이프라인 매트릭스

**외형 먼저**
* 장점 : 아트 작업자에게 자율성 부여
* 단점 : 최소한의 방향성은 결정되어야 함

**전투 매커니즘 먼저**
* 장점 : 캐릭터성이 높은 캐릭터 제작, 외형작업시간 단축

**스토리 먼저**
* 장점 : 세계관에 완벽히 어울림, 특정 세력 인원 보충시 유용

### 완벽한 캐릭터의 조건

* 기능적 역학
* 내면의 결핍
* 최적의 파이프라인
