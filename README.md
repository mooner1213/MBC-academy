# MBC Academy

게임 개발 학습 기록 저장소입니다. Git 기초, Unity 환경 설정, 게임 기획, 프로토타입 구현, VR/최적화 강의 정리까지 날짜별로 정리된 아카이브입니다.

이 저장소는 '실제 배포용 서비스 코드'라기보다, 학습 과정과 실습 기록을 남기는 포트폴리오용 학습 레포지토리로 구성되어 있습니다.

## 프로젝트 성격

- Git / 개발 환경 학습
- 게임 기획 문서 작성
- Unity 실습 및 프로토타입 구현
- UI, 스테이지, 적, 탄막, 체력 시스템 실습
- VR 최적화, URP, 셰이더 그래프, 스토리텔링 정리

## 핵심 학습 흐름

1. Git과 개발 환경 세팅
   - Git 기초, 버전 관리, Unity 설치, Visual Studio, Sourcetree

2. 기획 기반 학습
   - 게임 컨셉, 로그라인, 코어 루프, 디자인 필라, 시나리오, 캐릭터 설정

3. Unity 실습
   - 플레이어 이동
   - 총알 발사
   - 적 생성 및 스폰
   - 체력/코인/HP UI
   - 스테이지 구조

4. 심화 게임 개발
   - 적 패턴 제작
   - 전투 시스템
   - 스킬, 퀘스트, UI/UX, 밸런스 설계

5. 산업/실무 관점
   - VR 최적화
   - URP / 쉐이더 그래프
   - GC 및 메모리 관리
   - 서사와 공간음향

## 포트폴리오로 보여주기 좋은 부분

이 저장소의 강점은 단순한 문서 정리가 아니라, 개발 과정을 따라가며 쌓은 실습 기록이라는 점입니다.

다음 항목은 포트폴리오에 보여주기 좋습니다:

- Unity 환경 구성 및 Git 사용 역량
- 게임 기획서 작성 능력
- 프로토타입 설계와 구현 경험
- 적/플레이어/스폰/전투 시스템 설계 경험
- UI/UX와 밸런스 설계 이해
- VR 최적화, 렌더링, 성능에 대한 관심

## 포트폴리오용 추천 방식

이 저장소는 현재 다수의 학습 기록이 섞여 있어, 포트폴리오로 보여줄 때는 대표 프로젝트 중심으로 정리하는 것이 좋습니다.

추천 구성:

- `Unity 프로토타입 실습` 중심으로 대표 문서 정리
- `게임 기획 및 설계 문서`를 별도 포트폴리오 페이지로 분리
- `강의 정리`는 보조 자료로 유지
- 문서가 너무 많다면, 최신 3~5개 핵심 기록만 공개

## 사용 목적

이 리포지토리는 다음 목적에 적합합니다:

- 게임 개발 학습 과정 기록
- 프로젝트 성장 과정 확인
- 포트폴리오 자료 모음
- 실습 및 기획 문서 보관

## 요약

이 저장소는 단순히 코드만 담은 레포가 아니라, 게임 개발자로 성장하는 과정 전체를 기록한 아카이브입니다. 특히 Unity 실습과 기획 문서가 강점이며, 포트폴리오 정리 시에는 구조와 대표 문서만 정리해도 충분히 설득력 있는 자료가 됩니다.

다음 단계로는 이 repo를 포트폴리오용으로 더 깔끔하게 정리하려면:

- 루트 README를 기준으로 네비게이션 정리
- 대표 문서 3~5개만 공개용으로 분리
- 오래된 학습 메모는 `archive/`로 이동
- 핵심 프로젝트는 별도 repo로 분리

이 과정을 진행하면, GitHub 첫 화면에서 더 전문적으로 보이게 만들 수 있습니다.
