## 학습 방식

수업 내용을 따라 제작한 뒤 같은 에셋과 학습 자료를 바탕으로 AI를 활용해 기능을 재구현하는 학습을 진행했습니다. 기획 아이디어를 문서로 구체화하는 연습과 게임이 동작하는 구조를 이해하기 위한 실습을 함께 기록합니다.

## 자료의 성격

강의 내용과 개인 실습·기획 자료가 함께 있습니다. 문서가 존재한다는 사실만으로 해당 기능의 구현이나 최적화 성과가 입증되는 것은 아닙니다. 실제 구현과 시연은 개별 프로젝트 저장소를 기준으로 확인합니다.
