# MBC Academy

게임 개발 학습 과정을 기록하고 실습한 저장소입니다. 
이 리포지토리는 단순한 메모가 아니라, 게임 기획, Unity 실습, 프로토타입 구현, 전투 시스템 설계, UI/UX, VR/최적화에 대한 역량을 단계적으로 쌓아온 기록 아카이브입니다.

## 이 저장소가 보여주는 것

이 저장소는 완성형 게임 서비스라기보다, 개발자로서 성장하는 과정의 기록을 보여주는 포트폴리오 자료에 가깝습니다. 특히 아래 역량을 중심으로 구성되어 있습니다.

- 게임 기획서 작성 및 컨셉 설계
- Unity 환경 구성 및 C# 기반 구현 실습
- 플레이어/적/스폰/전투 시스템 설계
- UI/UX와 스테이지 흐름 이해
- VR/렌더링 최적화 및 실무형 개발 개념 학습

## 포트폴리오로 어필하는 포인트

### 1. 기획력
- 게임 컨셉과 코어 루프를 설계하는 과정 이해
- 유저 경험, 캐릭터 설정, 시나리오 기반 설계 경험
- 게임 시스템을 구조적으로 정리하는 능력

### 2. 구현 역량
- Unity와 C#를 활용한 기본 프로토타입 개발
- 이동, 총알, 적 생성, 체력, UI 관리 구현 경험
- 스테이지/시스템 구조를 설계하고 확장하는 능력

### 3. 개발 학습 역량
- Git, 개발 환경 설정, Unity 세팅에 대한 이해
- VR, URP, 셰이더 그래프, 최적화 개념 학습
- 게임 개발에서 성능과 UX를 함께 고려하는 사고방식
