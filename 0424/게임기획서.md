# 게임기획서

### 종류
1. **게임 제안서** : **게임 프로젝트 추진**을 계속하기 위해 작성된 문서
2. **컨셉 기획서** : **첫번째 게임 기획서, 게임 설명서**
3. **상세 기획서** : **게임 개발자**가 **실제 개발**하기 위해 **참조**하는 기획서
4. **리소스 기획서** : 게임에서 사용하는 **리소스의 정보(파일명, 설명, 분류)를 정리**한 문서

### 게임 제안서의 구성요소
1. **게임 개요** : 게임 제목, 기획 의도, 타겟, 테마, 배경, 스토리(시놉시스)
2. **게임 소개** : 플랫폼, 게임의 장르, 아트 컨셉, 게임의 비전, 래퍼런스, 게임의 방향, 게임의 지향점, 게임의 도전 요소
3. **주요 시스템** : 게임의 주요 시스템 소개
4. **예산 및 매출** : 개발 인력 투자 계획 및 개발 일정 산정, 예상 매출 계획

### 게임 제안서 작성
1. 핵심적인 재미요소를 선정하고 설명한다.
2. 짧고 간결하게 설명하는 것이 좋다.(한 페이지도 가능)
3. 마인드 맵 활용
4. 게임의 특성이 담긴 제목 / 부제
