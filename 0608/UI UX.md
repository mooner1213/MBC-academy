# UI / UX

**UI(User Interface) : 시각적 접점**
* 사용자가 직접 상호작용하는 화면 요소

**UX(User Experience) : 사용자 경험**
* 제품 사용 시 느끼는 전반적인 경험과 감정

### UI 디자인의 핵심 원칙
**직관성**
* 직관적인 UI의 정의
  * 즉각적인 항목파악
  * 쉬운 유추가 가능한 설계
 
* 직관성이 주는 심리적 효과
  * 신규 기능에 대한 거부감 방지
  * 사용자 친숙도 향상
 
**편의성**
* UI 편의성의 원칙과 장애물
* 실전 편의성 개선 : 단축키 활용

**일관성**
* 유저혼동의 완전한 제거
* 일관된 인터렉션 용어 사용

### 카메라 시점 가이드
**탑뷰**
* 위에서 아래로 내려다 보는 시점
* 각도를 조절하여 측면 노출
* 2D에서의 효과적인 입체감 형성
* 자유로운 다방면 캐릭터 이동

**사이드 뷰**
* 캐릭터와 맵을 옆에서 보는 시점
* 액션 및 슈팅게임에 최적화
* 공간감 표현의 어려움
* 이동방향의 제약

**쿼터 뷰**
* 대각선 방향에서 바라보는 시점
* 2.5D, 아이소메트릭 뷰
* 마름모꼴 형태의 맵 구성
* 2D게임의 입체화된 지형 구현

**백뷰**
* 1인칭 시점 : 캐릭터 본인의 시선으로 직접 세상을 바라보는 방식
* 3인칭 시점 : 캐릭터의 등 뒤에서 앞을 바라보며 캐릭터의 모습까지 확인하는 방식
* 광활한 시야 확보
* 현실감 기반의 높은 몰입도

### 카메라 시점 설정 가이드

1. 시점 기획 및 유형 정의 : 게임 성격에 맞는 시점 선택 / 시점 고정 및 변환 여부 결정
2. 위치 설정 및 최적화 : 플레이 테스트를 통한 위치 확정
3. 최종 검토 및 적용 : 최적의 카메라 설정 완료

### 카메라 시점 구성 가이드
* 시점 기본 위치 설정
* 시점 위치 변환 영역 설정

### 조작 설정과 입력 방식
* 조작 설정의 정의 : 유저가 게임 플레이를 위해 정보를 입력하는 방법을 설정하는 것을 의미
* 기획 초기 단계에서 결정 : 게임의 형태와 플랫폼을 결정할 때 기본 적인 조작 방식도 함께 확정
* 주요 입력 방식
  * 주변기기 이용 방식(PC, 콘솔) : 별도의 장치를 통해 게임에 명령을 입력
  * 화면 직접 입력 방식(모바일) : 유저가 직접 터치하여 조작하는 방식
