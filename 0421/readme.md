# AI

### AI의 변화

* 기존의 AI(분류형) : 패턴 학습을 통한 분류 및 예측(알고리즘, 스팸필터 등)
* 생성형 AI(창조형) : 기존 데이터를 학습하여, 텍스트, 이미지, 코드 등 새로운 콘텐츠를 창조.(chat GPT)

**어느순간, 사람을 뛰어 넘기시작했다.**(이세돌 vs 알파고)

### LLM?

**"Large Language Model"** 으로, **대규모 언어 모델** 이라고 한다.

llm은 문장의 맥락에서 다음에 올 확률이 가장 높은 '토큰(단어조각)'을 예측하여 문장을 완성한다.

이는 **맥락을 이해하는것이 아니라, 통계적 확률을 계산하는 것** 이다.

(ex. 학교 -> 종이 -> 땡땡땡 -> ??? / '어서모이자'일 확률 88%...99%...)

### 생성형 AI 모델 (2024-2025)

1. GPT - 4o(open AI) : 압도적 범용성, 데이터 분석 - **복잡한 자료조사, 엑셀/데이터 처리**
2. Gemini 2.5(google) : 구글 생태계 연동, 롱 컨텍스트 - **방대한 pdf 요약, 워크 스페이스 연동**
3. Claude 3.5(Anthropic) : 인간과 유사한 자연스러운 문체 - **자소서 초안 작성, 섬세한 텍스트 교정**
4. Llama 3(Meta) : 오픈소스 생태계 주도 - **기업 내부 보안용 AI 구축(구직자 참고용)**

### AI의 한계

1. 할루시네이션(환각) : **사실이 아닌정보를 마치 사실인 것처럼** 가장 높은 확률로 조합하여,자신있게 거짓말하는 현상.
2. 데이터 편향성 : 과거의 학습 데이터에 포함된 편견, 고정관념, **불균형이 결과물에 그대로 노출**될 위험.
3. 보안 이슈 : 기업의 기밀이나 개인정보를 무심코 입력할 경우, **AI의 새로운 학습 데이터로 흡수**될 위험.
