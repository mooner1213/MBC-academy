# 게임 기획에 대해

학기 초 오후에는 게임 기획에 대해 배운다.

책은 '현업 기획자 마이즈가 알려주는 **게임기획스쿨**' 이다.

기초부터 시작하는 게임 프로젝트 입문서로서, 읽기 굉장히 편하게 되있다고 한다.

대충만 봐도 문서 만드는거나, 딱딱하게 되어있는게 아니라, 소설이나 이야기처럼 편하게 읽어나가기 좋은 것 같다.

## 게임이란 무엇인가?
> 놀이의 본능에서 재미의 설계까지

**게임의 정의**를 알기 위해선, 과거로 가봐야한다.

명화 '아이들의 놀이'에는 여러가지의 전통 놀이들이 있다.

**공기놀이, 말뚝박기, 팽이치기, 굴렁쇠 등등**

1560년대의 그림이라고 한다. 이로부터 우리는 아주 옛날부터 즐거움이라는 것을 위해 놀이를 해왔다.

**요한 호이징하**는 인간을 **"놀이하는 인간"** 이라 명명하며, **놀이가 문화의 근원**이라고 정의했다.

### 놀이의 세가지 특성

1. **자유성** : 강요되지않은 자발적 참여
2. **비목적성** : 생존이나 경제적 보상이 아닌 행위 그 자체가 목적
3. **격리성** : 일상에서 벗어난 특수한 시공간 (흔히 과몰입이라고 하지ㅋㅋ음음ㅋ)

### 마법의 원

놀이는 현실의 물리적, 시간적 영역과 완전히 단절된 특수한 경계 안에서 발생한다.

이 원안에서는 현실의 법칙이 무효화되고, 오직 놀이의 규칙만이 존재한다.

(ppt안에 있는 이미지를 못찾았다. 교수님이 ppt를 안주셔서 아직 넣지 못함. 나중에 받으면 정리)

### 놀이의 진화
> 자유로운 에너지에 질서를 부여

* **파이디아(놀이)** : 유연하고 즉흥적인 규칙, 과정 자체의 즐거움 중심
* **루두스(게임)** : 엄격하고 고정된 시스템, 결과 중심의 구조화

### 게임의 조건

게임계의 거장들이 정의하는 **게임의 조건**이다.

* **제인맥고니걸** : 게임은 **불필요한 장애물**을 **자발적**으로 극복해 나가는 노력이다.
* **살렌&짐머만** : 게임은 **규칙**에 의해 정의된 **인위적인 갈등**에도 참여하며 **수량화된 결과**를 만들어내는 시스템이다.

### 게임의 4대 핵심 요소

1. **목표** : 무엇을 달성해야 하는가?(**동기부여**)
2. **규칙** : 무엇을 하면 안되는가?(**제약과 창의성 창출**)
3. **피드백** : 현재 얼마나 잘하고 있는가?(**레벨,점수,전투력 UI**)
4. **자발적 참여** : 이 모든 제약을 기꺼이 **수용하겠다는 합의**

### MDA 프레임 워크

#### 시스템이 재미를 창출하는 원리
---------------------
**M(메카닉스)** : 게임을 구성하는 **데이터**, **알고리즘**, **인위적 규칙**

**D(다이나믹스)** : 규칙안에서 **플레이어의 입력**과 **상호작용**으로 발생하는 **실시간 행위**

**A(에스테틱스)** : **시스템과 상호작용**하며 플레이어가 느끼는 **감정적 반응(재미)**

### 게임의 과거

> 시대 1 : 1970-1980 년대
* 1970 : **상업용 아케이드**의 시작(퐁, 스페이스 인베이더)
* 1980 : **게임의 대중화**(팩맨, 테트리스, 슈퍼 마리오)
* 1983-1985 : **아타리 쇼크**(무분별한 질적 저하가 불러온 산업의 위기와 교훈)
* 1989 : **휴대용 혁명**(닌텐도 게임보이 출시)

> 시대 2 : 1990-2000 년대
* 1993 : 최초의 FPS **둠**(3D 시점과 공간감의 혁명)
* 2000 : **심즈**(인생을 시뮬레이션하는 새로운 지평)
* 2002 : **헤일로**(멀티플레이어 콘솔 슈팅의 기준 확립)
* 2004 : **월드 오브 워크래프트**(대규모 다중 접속 세계의 확장 - **MMO**)
* 2009 : **E스포츠의 폭발**과 **모바일 시대**의 전조(리그 오브 레전드, 앵그리버드)

> 시대 3 : 2010-Present
* 2010 : **마인크래프트**(유저가 직접 창조하는 샌드박스 세계의 등장)
* 2012 : **모바일 게임 시장**의 폭발적 성장 기점(현재PC/시장규모초과)
* 2016 : **포켓몬GO**(현실과 가상을 융합한 AR의 대중화)
* 2018 : **포트나이트**(가상 소셜 공간으로의 진화)
