### 3. GIT 설치 하기
https://git-scm.com/downloads

- git 설치
- git bash 실행

**명령어**
  - 설치 버전 확인
 
    git --version
  - 사용자 이름 / 이메일 등록 진행

    git config --global user.name "사용자이름"

    git config --global user.email "사용자이메일"
  - 등록된 사용자의 정보 확인

    git config --list
