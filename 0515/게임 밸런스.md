# 게임 밸런스

### 범위 밸런싱
> 표준화된 시스템 수치와 사용자 인터페이스의 이원화

* **시스템 척도(0~100)**
  * 내부적으로 표준화된 범위를 사용, 계산과 비교를 수행한다. 데이터관리의 편의성과 시스템 안정성을 제공한다.

* **플레이어 척도(현실단위)**
  * 플레이어에게는 실생활에 가까운 척도(kg, m/s, Hp 등)을 제공하여 게임의 직관성과 몰입감을 높인다.
 
### 범위밸런싱의 수학적 작동방식
* 데이터 범위를 먼저 정의(최대 - 최소)
* 개별 오프젝트의 위상을 백분율(%)로 결정
* 유연한 범위 수정을 통한 밸런싱 대응

**최대 - 최소 x % + 최소 = 최종수치**

### 밸런스의 정중앙 기준점

* 단일 기준 : 활동, 사건, 상황에서 필수적인 역할을 수행하는 단일 비교 기준이다.
* 장르별 적응 : 레이싱 게임의 지렛목 차량, RPG의 지렛목 기본 검 / 캐릭터 등이있다.
* 기준의 잠금 : 테스트 완료 후 잠금 처리하여 다른 모든 오브젝트의 측정 기준이 된다.

### 지렛목 캐릭터 제작 / 테스트 프로세스

1. **지렛목 생성**
   * **속성 설정** : 힘, 민첩, 지능 등의 속성을 **예상 범위(0~100)의 정중앙인 50으로 설정**한다.
   * **테스트** : 지렛목 캐릭터를 **직접 조작**하며 **기준 감각을 확립**한다.
   * **잠금** : 완성된 지렛목은 **치명적 버그가 없는 한 수정하지 않는다.**
  
2. **지렛목을 활용한 데이터 제작**
   * **데이터 적용** : **새로운 오브젝트**에 **지렛목 데이터를 먼저 복사**한다.
   * **비교 밸런싱** : **지렛목과의 성능 차이를 조정**하며, **새로운 데이터를 완성**한다.
   * **교차 테스트** : **새로운 조합들 간의 상호작용을 검증**한다.
  
### 성장 지렛목의 필요성
> 게임 내 레벨업이나 성장 개념이 있다면, 단일 지렛목으로는 부족하다.
> 각 성장 구간별로 지렛목 캐릭터를 구축해야 한다.

**안전한 지점의 선택**
* 지렛목 캐릭터는 성장의 중간 지점(MID-Point)에서 시작하는 것이 가장 안전하다.

### 계층적 디자인
> 수정의 우선순위와 제작의 비전을 결정하는 선형 구조

### 게임 제작의 계층 구조

|계층 단계| 상세요소|비고|
|--|---|---|
|1. 핵심기반|게임 비전, 엔진, 콘솔플랫폼|가장중요한 의사결정 요소|
|2. 컨트롤 & UI|카메라, 컨트롤 입력, UI/UX|플레이어의 직접적인 인터렉션|
|3.데이터 지렛목|플레이어 캐릭터, 지렛목 적/npc, 레벨제약|수치밸런싱의 기준점|
|4.레벨 & 보상|개별 레벨디자인, 기하학적 경로, 시스템 보상||

### 지수 성장 시스템
> 게임경제와 플레이어 유지의 핵심 엔진

### 선형 성장 vs 지수 성장
* 선형 성장
  * 반복 횟수가 늘어남에 따라 총량이 일정하게 커지는 방식
  * ex. 매턴마다 2점씩 추가, 10턴 뒤 20점, 100턴 뒤 200점

* 지수 성장
  * 합계 또는 현재 크기에 비례하여 성장률이 점점 더 급격하게 올라가는 방식
  * 시간이 지날수록 입력 대비 출력의 양이 폭발적으로 증가한다.
 
### 지수성장 시스템의 필요성

* **초기 몰입 유도** : **초기에는 빠른 보상 주기**를 통해 플레이어를 게임에 강력하게 붙잡는다.
* **장기 애착 형성** : **후반부**로 갈수록 **목표 달성에 더 많은 노력을 요구**하여, 게임에 대한 깊은 애착을 만든다.
* **개발 유연성** : 새로운 메카닉을 빠르게 도입하고 **후반 보상 페이스를 개발 목표에 맞춰 조절**할 수 있다.

### 지수성장의 수학적 엔진

**지수 성장 공식 구조**
* 초기 시작 값 : 성장이 시작되는 최초의 기준수치
* 반복 계숫값 : 매 단계마다 곱해지는 증폭인자
* 반복 가산값 : 매단계마다 일정하게 더해지는 값
* 반복횟수
 
### 수확체감의 법칙
> 생산요소가 증가할수록 한계 생산량은 점차 감소한다.

**게임 내에서 고레벨 장비 획득을 위해 필요한 노력이 기하급수적으로 늘어나는 밸런싱의 근거가 된다.**
