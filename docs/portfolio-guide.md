# 포트폴리오 정리 가이드

## 1. 이 저장소의 정체성

이 저장소는 단일 제품 코드 저장소가 아니라, 게임 개발 학습 과정의 기록 아카이브입니다.

따라서 포트폴리오에서는 다음처럼 설명하는 것이 가장 자연스럽습니다:

> Unity와 게임 기획 학습 과정을 기록하며, 게임 메커니즘 설계와 프로토타입 구현을 반복해온 학습 저장소입니다.

## 2. 보여주기 좋은 항목

다음 요소들은 포트폴리오에서 가장 큰 강점이 됩니다.

- 게임 기획서 작성 역량
- 유니티 실습 경험
- 플레이어, 적, 스폰, 전투 시스템 구현 이해
- UI/UX와 스테이지 설계에 대한 이해
- VR 최적화 및 렌더링 최적화 관심

## 3. 포트폴리오에 추천하는 표현 방식

### 추천 소개 문구

- 게임 개발 학습 과정을 기반으로 Unity와 게임 기획 역량을 쌓아가고 있습니다.
- 게임 메커니즘 설계와 프로토타입 구현, UI/UX 구조를 이해하고 실습해 본 경험이 있습니다.
- 게임 개발 전반에 걸쳐 기획 → 구현 → 개선 흐름을 경험하며 학습하고 있습니다.

### 추천 태그

- `Unity`
- `C#`
- `Game Design`
- `Game Development`
- `Prototype`
- `VR`
- `Game UI`

## 6. 한 줄 결론

이 저장소는 '실제 게임 프로젝트'라기보다, 게임 개발자의 학습 성장 과정과 실습 기록을 담는 포트폴리오 아카이브에 가장 적합합니다.

이 점을 잘 살려 설명하면, 프로젝트 자체의 완성도가 아니라 "성장 과정과 학습 역량"을 보여주는 저장소로 훨씬 설득력 있게 보입니다.
