# 게임 이론
> 갈등과 협력의 수학적 구조부터 인공지능 기반 메커니즘 설계까지

**게임 이론** : **합리적 의사 결정자(무엇이 최선인가 스스로 판단하는 개인)** X **전략적 상호작용(타인의 선택이 나의 결과에 미치는 영향)**
> 이 **두가지 요소가 결합**하는 순간, **단순했던 세상**은, **고도의 심리전**과 **치밀한 예측**이 오가는 거대한 게임판으로 변한다.

### 합리적 의사 결정자

**다양한 선택지** 중, **스스로 본인에게 가장 효용을 주는 것은 무엇인가를 판단**하여, **최적의 행동을 선택**하는 것.

* **내결과**가 **나에게만** 달려있는가? 그렇다면, 게임이라 할 수 **없다**. 나의 결과가 **타인에게도 달려있다면** 게임이라 **할 수 있다.**

### 전략적 상호작용

* 나의 행동 : 내가 어떤 선택을 할 것인가?
* 타인의 행동 : 다른 사람들은 어떤 선택을 할 것인가?

**두 선택이 맞물려서 최종결과가 도출된다.**

### 일상 속 상황

* 학업 성적 : 절대평가(나의 노력 -> 나의 학점) / 상대평가(나의 노력 + 상대의 노력 -> 나의 학점)
* 스포츠 경쟁 : 기록 경쟁(내기록과 나와의 싸움) / 순위 경쟁(높은 순위를 위해 상대를 이겨야 함)
> 룰과 제도가 바뀌면, 평범했던 상황도 언제든 고도의 눈치싸움이 필요한 '게임'으로 돌변한다.

* 승부차기의 **딜레마** : **나의 최선이 고정되어 있지않다**는 것. **상대방의 선택**에 따라 **나의 정답이 결정**된다.
* 복도에서의 **충돌 딜레마** : 충돌을 피하기위해 **끊임없이 상대를 예측**함. 이 **예측이 누적**되어 **우측통행이라는 사회적 관습 정착**
**게임이론은 단순한 경쟁이 아니라, 사회가 어떻게 무질서에서 '균형'을 찾아 가는지를 설명하는 강력한 도구이다.**

  ### 예측의 거울
  * **타인의 마음을 읽어내는 예측과 예측이 무한히 중첩**되면서, 가장 **단순한 상황**조차 가장 **복잡한 심리전으로 진화**함.
 
  * **예측의 핵심 변수 : 내 앞의 상대방이 '어떤 부류의 사람인지' 파악하는 통찰력에 달려있다.**
 
  ### 게임 이론적 사고방식

  * **인간 본성** : 이익추구 vs 공정성
  * **타인의 예측** : 상대는 어떻게 움직일 것인가
  * **룰과 제도** : 경쟁인가 평화인가

   --> **나의 결정**

 ### 게임을 구성하는 세가지 요소

 * **플레이어** : 게임에 참여하는 의사 결정자. 각자 자신의 목표를 달성하기 위해 다향한 선택지를 가진다.
 * **보수** : 특정 전략 조합의 결과로 얻는 보상. 플레이어가 게임에서 궁극적으로 얻고자 하는 목표를 반영한다.
 * **전략** : 선택 가능한 행동의 집합. 게임내에서 어떻게 행동할지에 대한 구체적인 계획이다.

**모든 전략적 상황은 이 세가지 요소의 끊임없는 상호작용으로 작동한다.**

### 내쉬균형 : 이탈의 유인이 사라진 상태
> 여러 의사결정자가 참여하는 상황에서, 각 플레이어가 자신이 선택한 전략을 바꿀 유인이 전혀없는 안정된 상태.
* **최적의 믿음** : 각 플레이어는 자신이 선택한 전략이 **상대방의 전략에 대응**하는 **'최선의 전략'** 이라고 믿는다.
* **동시 만족** : **시스템 내의 모든 플레이어가 이 최적화 조건을 동시에 만족**해야만 **균형**이 성립된다.

### 균형의 3가지 역설적 특징

* **존재성** : 최소한 하나의 균형이 반드시 존재. 어떠한 혼란상황에도 수학적으로 증명된 안정감은 존재
* **다수성** : 여러 개의 내쉬 균형이 동시에 존재할 수 있음. 엄
* **효율성의 역설** : 교수님이 ppt 넘김 어캄?

### 행렬 vs 트리

* **전락적 / 정상형 게임 : 행렬**
> 동시선택

**모든 플레이어가 동시에 전략을 선택한다. 의사결정의 교차점을 시각화하기위해 주로 보수행렬 형태로 표현한다.**

(ex. 가위바위보)

* **확장형 / 전개형 게임 : 트리**
> 순차적 선택

**게임이 단계적으로 진행, 플레이어가 순서를 두고 전략을 선택한다. 시간의 흐름과 인과관계를 보여주는 트리로 표현한다.**

(ex. 장기, 체스)

### 전략적 상호작용 4가지 유형

* 협조 vs 비협조 : 구속력있는 약속 가능 여부
* 제로섬 vs 비제로섬 : 이익의 합이 0 인가?
* 동시 vs 순차 : 의사결정 시점과 정보
* 대칭 vs 비대칭 : 플레이어간 전략과 보수 구조의 동일성

### 제로섬 게임 : 누군가 얻으면, 누군가는 잃는 게임

* **제로섬 게임**
**합계는 언제나 0** : **누군가가 얻는 이득**은, **반드시 누군가의 손실**로부터 발생한다.

(ex. 한정된 자원, 승패가 확실한 스포츠 등)

* **비 제로섬 게임**
**득실의 합이 0이 아니다.** : 상황에 따라 **전체 파이가 커지거나, 작아질 수 있다.**

(ex. 윈윈, 모두의 손해)

### 죄수의 딜레마 : 개인의 선택과 결과의 매트릭스

* 격리된 두 명의 용의자 : 공범인 두 사람은 서로 의사소통 할 수 없는 별도의 수사실에서 자백 여부를 결정해야함.
* 이기심과 협력의 충돌 : 상대의 선택을 모르는 상태에서 자신이 석방되기 위한 최선의 선택이 무엇인지 고민하게 됨.

* **최선** : 둘 다 침묵 시 가장 낮은 형량을 받음.
* **최악** : 한 명만 배신하면 독박을 쓰게 됨.
