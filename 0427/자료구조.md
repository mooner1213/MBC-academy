### 문법의 진화

**최상위  문**
* 클래스와 main 이 꼭 필요했음.

* **Class** : **C# 프로그램의 기본단위**, 파일이름과 일치시키는 것이 관례
* **using System(네임 스페이스)** : C#의 **기본 도구 상자인 System**을 가져온다.
* **진입점** : 프로그램이 샐행될 때, **가장 먼저 시작되는 핵심 메서드(static void Main())**
* **출력명령어** : **System 안에 있는 Console 클래스의 WriteLine 매서드를 사용**해 **화면에 텍스트를 출력**함.(WirteLine())

### 개발자 근육 기억 만들기
* **결과 확인(Verify)** : 내 의도대로 터미널에 **결과가 출력**되었는지 **확인하고 코드를 이해**한다.
* **타이핑(Type)** : **복붙을 금지** **의식적**으로 **코드를 직접 입력**해야함.
* **빌드 및 실행(Run)** : **오류가 나면 수정**, **단축키(Ctrl + F5 등)로 실행**한다.

**Hello, World 에서의 문법 해석**

설명할 줄 알아야 함.
```
//[1] 네임 스페이스 선언부
using UnityEngine; // 현재 cs 파일에서 UnityEngine 네임스페이스를 사용

// [2] 클래스 선언부
public class HelloWorld : MonoBehaviour
{
    // Start is called once before the first execution of Update after the MonoBehaviour is created
    // [3] Start 메서드 선언, 정의 : 프로그램을 시작할때 1번만 실행
    void Start()
    {
        //[5] 명령문 : 콘솔에 "Hello, Unity!" 문자열 출력
        Debug.Log("Hello, Unity!");
    }

    // Update is called once per frame
    // [4] Update 메서드 선언, 정의 : 프로그램 시작후에 매 프레임마다 실행
    void Update()
    {
        
    }
}
```
