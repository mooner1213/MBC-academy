# 업그레이드 마작 · Upgrade Mahjong

**기존 마작에 '세 가지 중 하나를 고르는 증강 카드'를 결합하는 게임입니다.**

강력한 카드 효과로 기본 규칙과 승리 전략에 변화를 주는 것이 핵심 기획입니다. 현재는 기본 마작의 규칙과 대국 흐름 및 디자인·UI를 다듬고 있습니다. **증강 선택과 효과 시스템은 아직 구현하지 않았습니다.**

| 항목 | 내용 |
| --- | --- |
| 제작 형태 | 1인 기획·제작 |
| 핵심 기획 | 증강 카드 3개 중 1개를 선택해 다른 전략으로 승리 |
| 현재 작업 | 기본 규칙·진행 오류 수정과 디자인·UI 보완 |
| 현재 프로토타입 | 리치 마작 기반 로컬 대국 · 사용자 1명과 컴퓨터 3명 |
| 이후 제작 | 최종 UI와 증강 선택·적용 시스템 |

## 기획의 중심

기본 마작의 패 구성과 타패·울기·화료 판단 위에 새로운 규칙 선택을 더하려는 기획입니다. 플레이어는 제시된 세 효과 중 하나를 선택하고 해당 효과를 활용한 승리 전략을 찾게 됩니다.

증강의 강력함 자체와 함께 선택 이후 무엇이 달라졌는지를 이해할 수 있는 화면과 규칙 설명이 필요합니다. 구체적인 카드 목록과 제시 시점·지속 범위·중첩 조건은 후속 설계 항목입니다.

| 요소 | 설계 방향 | 상태 |
| --- | --- | --- |
| 기본 대국 | 패와 가능한 행동을 읽고 대국 진행 | 구현·보완 중 |
| 세 가지 중 하나 선택 | 이번 대국에 활용할 효과 결정 | 기획 방향 · 미구현 |
| 규칙·전략 변화 | 기존과 다른 승리 경로 탐색 | 구체 효과 후속 설계 |
| 최종 UI | 가능한 행동과 선택 결과·적용 효과 전달 | 예정 |

## 현재 코드에 포함된 범위

| 구분 | 포함된 처리 |
| --- | --- |
| 대국 흐름 | 패 분배와 쯔모·타패·턴 진행 |
| 행동 | 치·퐁·깡·리치·론·쯔모·패스 및 복수 조합 선택 |
| 패와 점수 | 화료 형태·대기패·샨텐과 역·판·부·도라 계산 |
| 컴퓨터 플레이어 | 샨텐·유효패 수·도라 보존 등을 고려한 타패 판단 |
| 화면 | 작탁과 패·버림패·도라 및 플레이어 정보·행동·결과 UI |

위 표는 현재 코드에 처리 로직이 포함되어 있다는 뜻입니다. 모든 리치 마작 규칙의 정확성이나 최종 게임 완성도가 검증된 결과는 아닙니다. 온라인 대전도 현재 제작 범위가 아닙니다.

## 기본 게임을 먼저 다듬는 과정

잘못된 규칙과 진행 및 화면 문제를 수정하며 기본 대국의 흐름을 보완하고 있습니다. 화료·역·점수와 울기 조건 및 복수 행동 선택이 일관되게 이어지는지 확인해야 합니다.

현재 프로토타입에는 진행과 컴퓨터 판단·UI 연결이 한 클래스에 많이 모여 있습니다. 규칙과 화면 관련 모듈이 존재하지만 책임 분리와 구조 개선을 완료했다고 소개하지 않습니다.

## 증강 제작 전에 정리할 항목

- 증강을 고르는 시점과 선택한 효과의 지속 범위
- 기본 규칙과 증강 효과가 충돌할 때의 처리
- 효과 중첩 여부와 카드별 적용 조건
- 활성 효과와 바뀐 규칙을 보여 주는 화면
- 선택 결과를 비교할 수 있는 시험 대국과 기록

이는 앞으로 설계·검증할 항목입니다. 확정된 카드 효과나 밸런스 수치가 있는 상태는 아닙니다.

원본 개발 저장소는 비공개로 유지합니다. 이 페이지는 현재 기획과 제작 단계의 공개 소개이며 증강 적용 화면과 시연 영상은 아직 제공하지 않습니다.
