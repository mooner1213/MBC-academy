# MyLittlePet · VRtest

**가상 강아지의 움직임과 돌봄 상호작용을 다듬은 VR/MR 프로토타입입니다.**

팀 프로젝트에 사용할 기능을 먼저 만들고 시험한 작업 저장소입니다. 강아지가 자연스럽게 걷고 사용자의 손길과 공에 반응하도록 행동·애니메이션·상태 변화를 연결했습니다.

| 항목 | 내용 |
| --- | --- |
| 제작 형태 | MyLittlePet 팀 프로젝트용 기능 제작·시험 |
| 본인 담당 | 강아지 행동과 애니메이션 개선. 들기·공놀이·쓰다듬기. 관계·상태 상호작용 |
| 제작 방식 | 문제 관찰과 구체적인 수정안 작성 → AI를 활용한 코드 수정 → 직접 확인과 반복 피드백 |
| 검증 | Quest 환경에서 담당 기능 테스트. 모서리·장애물·바닥 이탈 복구 회귀 시험 수행 |
| 공개 자료 | [작업 저장소와 상세 README](https://github.com/PetopiaMBC/VRtest) |

이 소개는 본인이 제작·시험한 기능을 기준으로 합니다. 팀 통합본의 최종 반영 범위를 설명하는 자료와는 별도로 관리합니다.

## 상호작용 설계

| 사용자 행동 | 강아지의 반응과 연결 |
| --- | --- |
| 가까이 다가가거나 멀어지기 | 바라보기와 추적 및 걷기·달리기 전환 |
| 쓰다듬기 | 접촉 움직임 판정과 반응 애니메이션 및 하트 표현 |
| 공 던지기 | 추격 → 물기 → 반환과 실패 시 재시도 |
| 강아지 들기 | 들린 자세 유지와 머리·꼬리의 작은 움직임 |
| 돌봄 상호작용 | 호감도·배고픔·피곤함 변화와 행동·애니메이션 연동 |

호감도·게이지와 관계에 따른 반응은 본인이 설명한 구현 범위입니다. 공개 코드에서 확인한 내부 허기·피로 처리와는 구분하며 시연 자료를 통해 추가로 연결할 항목입니다.

## 관찰한 문제와 개선 과정

### 애니메이션이 끊기거나 같은 행동을 반복하는 문제

처음 애니메이션을 적용했을 때 전환이 끊기고 조건이 겹치면 같은 동작만 반복되는 상황이 있었습니다. 걷기 동작과 실제 이동 속도가 맞지 않아 발이 미끄러지는 현상도 관찰했습니다.

문제가 발생하는 조건과 원하는 동작 전환을 하나씩 구체화해 AI에 수정 방향을 전달했습니다. 수정 결과를 플레이하며 남은 어색함을 찾고 피드백을 반복했습니다. 진행 중인 동작의 종료를 고려한 전환과 이동·애니메이션 속도의 연결을 다듬었습니다.

### 들고 있는 강아지의 자세와 생명감

들기 자세가 어색하고 들고 있는 동안 거의 움직이지 않는 문제가 있었습니다. 참고 사진과 그림으로 원하는 자세를 전달하고 결과를 비교했습니다.

기본 Idle 애니메이션의 머리 부분 적용과 꼬리 움직임을 추가해 전신 자세를 유지하면서도 작은 반응이 이어지도록 표현을 보강했습니다. 리깅 수정과 새로운 애니메이션 제작도 시도했습니다.

### 공놀이 중 진행이 멈추는 상황

공을 물지 못하거나 모서리·장애물 주변에서 접근이 막히는 상황과 바닥 아래로 공이 이탈하는 상황을 다뤘습니다.

포획 실패 시 재추격과 안전 바닥 복구 등을 구성하고 해당 상황의 회귀 시험을 진행했습니다. 정상적인 공놀이 흐름과 실패 후 복귀를 함께 확인했습니다.

### 쓰다듬기 입력과 반복 반응

손이 닿아 있기만 하거나 미세하게 떨리는 상황과 실제 쓰다듬는 움직임을 구분하도록 접촉 이동 거리·시간을 확인하는 처리를 구성했습니다. 공이나 강아지를 들고 있을 때 다른 상호작용과 충돌하는 조건도 다뤘습니다.

## 시험과 자료 현황

- Quest 환경에서 담당 기능을 테스트했습니다.
- 모서리와 장애물 주변 및 바닥 이탈 상황의 복구 회귀 시험을 수행했습니다.
- 시연 영상 제작과 시험 결과 정리를 완료했습니다. 이 소개 페이지에는 해당 파일을 아직 연결하지 않았습니다.
- MR 공간 데이터·권한과 경로 검증 및 장시간 성능 측정·공간 음향은 다른 담당 영역입니다.
- 행동 AI와 들기 로직의 구조 개선 완료 여부는 별도 코드 검토가 필요합니다.

외부 강아지 모델과 애니메이션을 활용했습니다. 본인의 기여는 행동·상호작용 연결과 수정 방향 제시 및 결과 확인 과정에 있습니다.
