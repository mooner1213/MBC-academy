## 작업 방식

1. 플레이어가 할 행동과 그 결과를 규칙·흐름·화면으로 구체화합니다.
2. AI를 활용한 제작 결과를 직접 확인하고 의도와 다른 부분을 찾습니다.
3. 문제 상황과 기대하는 동작을 구체적인 수정안으로 전달합니다.
4. 수정 결과를 다시 확인하고 피드백을 반복합니다.

일시정지!에서는 프로그래밍을 제외한 기획·디자인 전반을 맡았습니다. MyLittlePet에서는 동물의 움직임과 상호작용을 관찰하며 구체적인 수정 지시와 반복 검증으로 표현을 다듬었습니다. 프로젝트별 역할은 각 소개 페이지에서 확인할 수 있습니다.
