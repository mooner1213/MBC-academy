### 인식의 한계 / 조밀도

* **단순함이 주는 명확성**
  * 가독성을 위해 2~3자릿수 사용
  * 내부 계산은 소수로 하되, 노출은 정수로한다.

### 계산의 불편함이 만드는 긴장감

* 부정적 감정 유발 : 공포나 서바이벌 장르에서 효과적
* 긍정적 감정 유발 : 캐주얼게임이나 안정적인 성장단계에 적합

### 게임 시스템 디자인을 위한 기초 지식

**속성 가중 값 : 밸런싱의 핵심**

* 속성 가중 값 : 각 속성에 적용해서 어느 속성이 다른 속성보다 얼마나 더 중요한지를 보정하는 계수
  * 맨처음 데이터를 설정할 때 중립적으로 1.0 에서 시작한다.
  * 테스트를 시작하면 속성마다 가치가 동일하지 않고, 가중값을 사용해 수정해야 할 수도 있다.

### 속성 밸런스 잡기

* DPS(초당 피해랑) : 캐릭터의 피해속성과 공격속도 속성 양쪽이 얽혀있음
  * 피해 속성만 보거나, 공격속도 속성만 본다면 캐릭터가 얼마나 강한지 정확히 알 수 없다.
 
* DPM(분당 피해랑)

### 오브젝트 이름 짓기 규약

* cha : 플레이어용 캐릭터
* npc : 우호적 논플레이어 캐릭터
* bad : 적 캐릭터
* pow : 파워업, 부스트아이템
* wep : 무기 아이템
* amr : 갑옷 아이템
* vhc : 탈 것

**상위 범주 뒤에 하위 범주를 둔다.**

* 게임 오브젝트를 설명하는 명사
* 속석을 설명하는 이름 추가
* Cha_Narwhal_Big_Fast_Blue(스네이크 표기)
* ChaNarwhalBigFastBlue(카멜 표기)

### 반복 오브젝트 이름 짓기

1. New 레이블의 문제점 : 새로운 오브젝트를 만들때 이름에 New 단어를 붙이면 문제가 발생함.

2. 반복 이름 짓기 방법 : 버전 번호 달기
   * Cha_Narwhal_Big_Fast_Blue_01
   * Cha_Narwhal_Big_Fast_Blue_02
   * Cha_Narwhal_Big_Fast_Blue_03

3. 특수한 사례에 쓰이는 용어
   * 삭제요망(deleteme)
   * 사용중지(deprecated)
   * 테스트(test)
   * 날짜 / 시간 : Cha_Narwhal_Big_Fast_Blue_2026_05_14
  
### 악수 공식을 활용한 밸런싱 작업량 추산

1. 게임 오브젝트를 다른 게임 오브젝트와 서로 비교하여 밸런싱
   * 테스트, 수정, 밸런스 조정 및 재조정 처리
  
2. 악수 공식
   * 한 무리의 의사가 한 방에 함께 있다. 각의사는 방안의 모든 의사들과 악수를 해야한다.
   * 의사들이 서로 모두 악수를 나누려면, 몇 번의 악수가 필요할까?
  
3. 가능성 그리드
   * 스프레드 시트에서 조합을 도식적으로 수행
  
4. 공식
   * (게임 오브젝트 수 X 게임 오브젝트수 - 게임 오브젝트 수) / 2
