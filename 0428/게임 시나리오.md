# 게임 시나리오
> 서사는 부차적 요소가 아닌, 플레이어의 몰입을 촉발하는 '활성화 에너지'이다.

**소설적 접근(문학적 완성도)**
* 선형적 사건 나열
* 분위기와 감성 전달 목적
* 비구조적 텍스트

**데이터 중심적 특성(비즈니스/시스템 작업물)**
* 다차원적 구조체
* 캐릭터 행동 양식 및 물리적 규칙 정의
* 시스템 주입을 위한 ID값 기반 리소스화

**개연성을 위한 데이터 리소스화**
> 시나리오는 단순한 스토리가 아니다. 게임세계의 합리적 규칙과 상호작용의 근거를 설계하는 '기초 데이터 패킷'이다.

**텍스트 수정(오류 : 텍스트는 언제든 수정 가능하다.)**
* 캐릭터/배경 에셋 양산 진행 -> **설정과 외형의 불일치 발생**

-> **에셋 전면 재작성**(3D모델링, 애니메이션, V/O 등 **막대한 매몰 비용** 발생)
> 기획역량이 결여된 단순 '텍스트 중심 스토리텔링'은 최종 제품의 완성도를 치명적으로 하락시킨다.

**이미 구축된 게임 시스템** + **뒤늦은 서사 개입(억지 설정 강제)** = **에러발생(플레이경험과 서사의 분리, 개연성 심각 훼손)**

### 작은 서사(마이크로 내러티브)
> 매력적인 텍스트 한 줄은 고가의 그래픽 리소스 없이도 몰입을 유도하는 최고 ROI의 전략적 도구이다.

(드라마에서의 조연, 영화에서의 씬 스틸러 등)
주인공과 이야기를 하며 자연스러운 메인 서사 진행에 대한 도움

* 유저 애착도 상승
* 그래픽 리소스 추가비용 '0'
* 생명령 및 소유욕 자극

### RPG 시나리오 생태계(모든 개발 부서의 중심축)
> 시나리오 설정이 명확할수록 3D 모델러와 원화가의 무엇을 만들지 고민하는 시간이 단축된다.

**세계관 시나리오는 모든 시스템에 영향을 준다.**
* **Art pillar**
  * 지역 / 캐릭터 / 무기 설정
  * 아트 콘셉트 / 디자인
* **Content Pillar**
  * 스토리
  * 퀘스트 / 대사
* **System Pillar**
  * 시스템(플레이) 규칙
 
**세계관 설정 --(시각적 불확실성 제거)-> 지역 / 캐릭터 / 논리 구축 --(시각적 불확실성 제거)->**

**아트 콘셉트 확립 --(시각적 불확실성 제거)-> 최종 시각적 결과물(배경 / 몬스터 디자인)**

### 시나리오의 궁극적 효용성(예술을 넘어선 경제적 가치 창출)
* **수익성 강화 : 잔존율 동력**
  * 유저의 장기적 체류 유도
  * 게임의 완성도 결정
  * 지속적 매출 증대와 직결
 
* **비용 및 리스크 절감 : 의사 결정 비용 감소**
  * 불필요한 에셋 수정 방지
  * 개발 기간 단축
  * 현금 흐름의 획기적 개선
