# 스킬 시스템

### 게임 스킬 핵심 분류
* 패시브 스킬
  * 습득 시, 계속 지속되는 효과
  * 전용 포인트 소비되지 않음.
* 액티브 스킬
  * 습득 후, 직접 선택하여 사용해야만 효과가 발생
  * 사용할 때마다, 전용 포인트가 소비됨
 
### 턴기반 스킬 발동 방식
* 턴 베이스
  * 자기 턴이 돌아온 후 발동 : 스킬 선택 후 자신의 차례가 되야만 실제 효과가 나타남.
  * 공격속도로 턴 시간 결정 : 다음 턴이 돌아오는 주기는 일반적으로 캐릭터의 공속수치를 활용
* 비 턴 베이스
  * 선택 즉시 발동 : 현재 진행 중인 턴과 상관없이 스킬을 선택하는 즉시 발동
  * 인스턴트 스킬로 명명 : 턴의 제약을 받지 않는 즉각형 스킬을 의미
 
### 시전 시간에 따른 밸런스 설계
* 즉시 시전 스킬
  * 대기시간이 없는 즉각 발동 : 캐스팅 없이 바로 발동 되어, 긴박한 전투상황에서 빠른 대응 가능
  * 위력이 대부분 낮고, 포인트 및 횟수 제한이 존재
* 사전 준비 필요 스킬
  * 설정된 캐스팅 시간 소요 : 스킬 선택 후, 정해진 준비시간이 지나야지만 실제 효과가 발동 가능
  * 위력이 상대적으로 강하나, 준비시간, 시전시간이 필요
 
### 게임 스킬의 5가지 핵심 분류 가이드
* 직접 전투 참여
  * 공격스킬 : 적이나 상대방에게 직접적으로 대미지를 입히는 가장 기본적인 형태의 스킬
  * 회복스킬 : hp회복이나 스텟이상을 치료하여 아군의 생존을 도움
* 전술적 지원
  * 버프와 디버프 : 아군을 방어하고 강화하거나, 적의 능력을 약화
  * 소환 : 특정 개체를 출력하여 정해진 기간동안 캐릭터의 전투를 보조
 
### 거리와 범위에 따른 분류
* 근거리, 원거리 스킬
  * 근거리 : 근접 무기 사거리 내의 근거리형
  * 원거리 : 스킬별 사거리가 다른 원거리형
* 범위 스킬
  * 일정 범위 안에서 효과가 발생, 반드시 범위를 정하는 기준점이 필요
    * 3가지 기준점 설정
      * 시전자 중심
      * 공격 대상
      * 특정 맵 지역
    * 적용 형태와 방향성
      * 직선 : 시전자를 기준으로 한쪽 방향으로만 효과 발생
      * 부채꼴 : 시전자를 기준으로 한쪽 방향으로 넓게 효과 발생
      * 반경 : 시전자 좌표 혹은 선택한 맵 좌표를 기준으로 일정 반경 내 적용
     
### 효과 적용 시간에 따른 분류
* 죽시 효과 : 시전 시점에 1회 즉시 적용
* 지속 효과 : 설정된 시간동안 일정 간격 발동
